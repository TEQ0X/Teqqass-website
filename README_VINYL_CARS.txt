NEW FEATURES
1. Transfer vinyl (single) — enter source email:password, target email:password, and Car ID; copies body/window vinyl onto the same CarID on target
2. Transfer vinyl (all) — enter source and target email:password; copies matching CarIDs only
3. Clone single car — enter source and target email:password plus Car ID; injects that full car into the target
4. Clone cars (all) — enter source and target email:password; injects the source garage into the target
5. Copy plates — enter source and target email:password; copies platesData to the target
6. Clone account — enter source and target email:password
7. Bulk clone — enter source email:password and a count; the tool creates new target accounts automatically
The target car must already exist on the target account. Only vinyl fields are transferred; body paint, vehicle parts, and unrelated car data stay with the target. Results are also sent on Telegram. Jobs keep running if Mini App closes.
