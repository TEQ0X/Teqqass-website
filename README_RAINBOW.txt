CUSTOM RAINBOW NAME AND ID

Custom Rainbow Name asks for the name text to save; Custom Rainbow ID asks for the ID text to save. Both use the built-in rainbow color sequence, repeated per character. No HEX colors or palette need to be entered. The Mini App reads the saved CPM color tags and colors each corresponding text segment with the same color.

Car cloning and siren helpers strip rainbow tags when they need the original CPM ID for generated car references. CPM formatting references confirm [HEX] tags for names, but do not verify ID rendering; if the game does not parse color tags for IDs, it may show them literally.
